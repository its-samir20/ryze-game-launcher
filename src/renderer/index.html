    About App
    RYZE Game Launcher
    RYZE Game Launcher is a Windows desktop app for quest enthusiasts. It browses the public game database, builds your personal game library, and launches games with a fake game window for rich presence.
    Version …
    Last update: …
    How it works
    • Browse & search games from the game database
    • Add games to your library and mark favorites
    • Launch a game with one click — shows "Playing" status
    • Recently played games are tracked automatically
    • Create desktop shortcuts for any game
    • Customize themes, startup options and system tray behavior
